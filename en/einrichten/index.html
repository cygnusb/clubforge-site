Setup assistant

Fill in what makes your club yours; the assistant puts together the installation commands, ready to copy. Everything stays in this browser, and it never asks for passwords.

Prefer the terminal? sudo bash install.sh without further options asks the same questions on the server. Explained step by step: Installation guide.

1. Route
2. Names

Three addresses in your domain point at the server. They cannot be changed later.

Adjust the names (default: app., sync., login.)
3. Club

The first admin signs in with the admin email.

4. Optional
Logo and colors

You can change them in the app at any time.

Your own word for “group”

The app’s default language is German, so the word and its article are German (for example Team, Teams, das).

Sending mail (SMTP)

Without it the server sends no mail; the app and push work anyway. Use port 587; many providers block 25 and 465. You enter the password on the server only.

Storage for attachments (S3)

For photos, files, and GPX routes, such as Hetzner Object Storage. A private bucket of its own, not the backup one. You enter the secret key on the server only.

Your own backup key

Without one, the installer creates a key. Cleanest: on your own computer run age-keygen -o key.txt, put the secret part in the password manager, and enter only the public one here.

5. Hetzner

Your commands

1. On the server: get and check the installer

curl -fsSLO https://cygnusb.github.io/clubforge-site/install.sh
curl -fsSL  https://cygnusb.github.io/clubforge-site/install.sh.sha256
sha256sum install.sh     # must match the checksum shown

2. Enter passwords hidden

Paste this block on its own and type the passwords; they don’t show and are stored nowhere.


    

    
Install

    

    
The installer’s messages are in German. Afterwards: open https:// plus the app address, sign in with the one-time password, and secure the backup key (guide, step 5).

  


  

    
1. Project and fixed IP

    
At console.hetzner.cloud, create a separate project and sign the data processing agreement. Under Primary IPs, create an IPv4 address in .

    
2. DNS

    
Point the three A records at this IP and check them before the server starts:

    

    
3. Create the server

    
Same location as the IP, image Ubuntu 24.04, type , the primary IP from above as the public IPv4, and your SSH key. Optionally a firewall with incoming 22, 80, and 443. Paste this into the Cloud config field:

    

    

    
4. Watch and collect the credentials

    
ssh root@<ipv4> tail -f /var/log/clubforge-install.log     # until the check.sh report
ssh root@<ipv4> cat /root/clubforge-erste-anmeldung.txt
ssh root@<ipv4> cat /root/clubforge-backup-key.txt        # into the password manager
ssh root@<ipv4> rm /root/clubforge-erste-anmeldung.txt /root/clubforge-backup-key.txt

    
If the installation stops because of DNS: fix the records, then run ssh root@<ipv4> /root/clubforge-install.sh.

    

      
5. After the installation: passwords into the settings

      
cloud-init doesn’t carry the mail password or the attachment secret key, so they aren’t readable at the provider. Add them to /opt/clubforge/deploy/.env, replacing the placeholders:

      

      
cd /opt/clubforge/deploy && docker compose up -d --force-recreate api worker

    

  


  

    
1. Token and template

    
At console.hetzner.cloud, create a separate project, sign the data processing agreement, and under Security › API tokens create a token with read and write access. On your own computer (with OpenTofu and Docker):

    
export TF_VAR_hcloud_token='…'     # your token, in the terminal only

    

    
2. terraform.tfvars

    
Save as terraform.tfvars in the hetzner directory (server type ):

    

    
3. Fixed IP and DNS

    
tofu init
tofu apply -target=hcloud_primary_ip.v4
tofu output ipv4

    
Point the three A records at this IP (with a zone in Hetzner DNS, the next step does it for you) and check:

    

    
4. Create the server

    
tofu plan
tofu apply
$(tofu output -raw installationsprotokoll)    # progress until the check.sh report

    
5. Collect the credentials

    
ssh root@$(tofu output -raw ipv4) cat /root/clubforge-erste-anmeldung.txt
ssh root@$(tofu output -raw ipv4) cat /root/clubforge-backup-key.txt    # into the password manager
ssh root@$(tofu output -raw ipv4) rm /root/clubforge-erste-anmeldung.txt /root/clubforge-backup-key.txt

    

      
6. After the installation: passwords into the settings

      
Add mail and the attachment secret key to /opt/clubforge/deploy/.env, replacing the placeholders:

      

      
cd /opt/clubforge/deploy && docker compose up -d --force-recreate api worker
