Wie man das liest

  • clubforge passt, wenn der Verein seine Daten selbst in der Hand haben will, offene Software bevorzugt und jemanden hat, der einen kleinen Server betreut (selbst oder über einen Dienstleister).
  • Ein fertiger Dienst passt, wenn niemand einen Server betreuen soll und der Verein dem Anbieter die Daten anvertrauen möchte.
  • Kombinieren geht auch: clubforge übernimmt die Mitgliederliste aus easyVerein und gleicht sie stündlich ab. Termine lassen sich als Kalender-Abo in andere Kalender holen.
