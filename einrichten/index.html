Einrichtungs-Assistent

Tragt ein, was euren Verein ausmacht; der Assistent stellt die Befehle für die Installation zusammen, zum Kopieren. Alles bleibt in diesem Browser, und Passwörter fragt er nie ab.

Lieber im Terminal? sudo bash install.sh ohne weitere Angaben fragt dasselbe auf dem Server ab. Schritt für Schritt erklärt: Anleitung.

1. Weg
2. Namen

Drei Adressen eurer Domain zeigen auf den Server. Sie lassen sich später nicht mehr ändern.

Namen anpassen (Standard: app., sync., login.)
3. Verein

Die erste Admin-Person meldet sich mit der E-Mail der Administration an.

4. Optional
Logo und Farben

Später jederzeit in der App änderbar.

Eigener Begriff statt „Gruppe“
Mailversand (SMTP)

Ohne verschickt der Server keine Mails; App und Push laufen trotzdem. Port 587 nehmen, viele Anbieter sperren 25 und 465. Das Passwort gebt ihr erst auf dem Server ein.

Speicher für Anhänge (S3)

Für Fotos, Dateien und GPX-Strecken, z. B. Hetzner Object Storage. Eigener, privater Bucket, nicht der der Backups. Den Secret Key gebt ihr erst auf dem Server ein.

Eigener Backup-Schlüssel

Ohne Angabe erzeugt der Installer einen. Am saubersten: auf dem eigenen Rechner age-keygen -o schluessel.txt, den geheimen Teil in den Passwortmanager, hier nur den öffentlichen eintragen.

5. Hetzner

Eure Befehle

1. Auf dem Server: Installer laden und prüfen

curl -fsSLO https://cygnusb.github.io/clubforge-site/install.sh
curl -fsSL  https://cygnusb.github.io/clubforge-site/install.sh.sha256
sha256sum install.sh     # muss mit der angezeigten Summe übereinstimmen

2. Passwörter verdeckt eingeben

Diesen Block allein einfügen und die Passwörter eintippen; sie erscheinen nicht und landen nirgends gespeichert.

4. Zusehen und Zugangsdaten abholen

    
ssh root@<ipv4> tail -f /var/log/clubforge-install.log     # bis zum Bericht von check.sh
ssh root@<ipv4> cat /root/clubforge-erste-anmeldung.txt

Bricht die Installation wegen DNS ab: Einträge korrigieren, dann ssh root@<ipv4> /root/clubforge-install.sh.

    

      
5. Nach der Installation: Passwörter in die Einstellungen

      
Mail und den Secret Key für Anhänge nimmt cloud-init nicht mit, damit sie nicht beim Anbieter lesbar sind. In /opt/clubforge/deploy/.env ergänzen, Platzhalter ersetzen:

      

      
cd /opt/clubforge/deploy && docker compose up -d --force-recreate api worker

    

  


  

    
1. Token und Vorlage

    
Bei console.hetzner.cloud ein eigenes Projekt anlegen, Vertrag zur Auftragsverarbeitung abschließen, unter Sicherheit › API-Tokens ein Token mit Lesen und Schreiben erzeugen. Auf dem eigenen Rechner (mit OpenTofu und Docker):

    
export TF_VAR_hcloud_token='…'     # Token einsetzen, nur im Terminal
